Solara Bay is an original open-world crime game in the browser: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and run five story missions. Built with three.js, fully offline, no network requests.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 to play.
